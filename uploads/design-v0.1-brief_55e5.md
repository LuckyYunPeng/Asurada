# CommitDock 设计基础 v0.1（工程摘录）

来源：https://cursor.com/canvas/store-36f26907-0294-48b6-a314-f6726d50b206/5561852d-3164-49af-8fd6-949995983bc1

## 产品
- macOS；无独立主窗口；边缘吸附小 tag → 点击展开浮层面板
- 面板：增删本地项目路径；每项一键「提交并推送」
- 执行：在项目目录非交互调用本机 `pi --print` + 固化提示词 → 分析 git status/diff → 中文 Conventional Commit（type 可英文）→ 无确认 `git add -A && git commit && git push` → 面板回写
- 非目标：不做 PR/MR、冲突解决向导、完整 git GUI
- 开源 MIT

## IA / 布局
- Tag 常驻；面板贴同侧，宽约 320–360pt，高自适应上限约 480pt，超出内部滚动
- 顶栏：标题 CommitDock +「添加项目」+ 收起
- 风险条常驻（列表上方）：明示会直接 push、不再确认；非 modal
- 项目行：名称、短路径（中间省略保末两段）、状态摘要、主按钮、⋯（移除；可选 Finder）
- 行内结果区：成功/失败摘要，默认折叠可展开；不用 Toast

## 状态
- 空列表：说明 + 唯一 CTA「添加项目」（可无风险条）
- 有变更：按钮可用
- 工作区干净：脚手架先按「主按钮禁用」（产品待拍板）
- 进行中：按钮「提交中…」+ 转圈；该行不可重复点；其他行仍可操作；面板可收起任务继续
- 成功：绿点 + `已推送 · <type>: <中文>`
- 失败：红字原因；按钮恢复；可选复制错误
- Tag：有未读失败时小红点

## 文案（中文优先）
- 风险条：一键将暂存、提交并推送到远端，不再确认
- 主按钮：提交并推送 / 提交中…
- 空态：还没有项目 / 添加本地 git 仓库后，可一键生成中文提交并推送
- 干净 / 有变更：工作区干净 / 有未提交变更

## 视觉
- 跟随系统浅/深色；系统材质背景
- 标题 15–16 Semibold；正文 13；辅助 11–12
- 间距 8/12/16；面板圆角 10–12；按钮 6–8
- 主色系统 Accent；成功绿 / 风险琥珀 / 错误红

## 工程约束
- Tauri 2，macOS 优先
- App 侧以 CLI 非交互为准（对齐 pi-git-shortcuts /cp 思路，但不做交互）
- 最小完整改动；本任务只搭可编译骨架 + 面板壳 + 项目列表持久化接口 + pi 调用占位
- 不要开 GitHub PR；Origin new_repo 直接落 main 即可
